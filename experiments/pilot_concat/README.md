# Pilot: do DINO image features complement Utonia point features?

A ScanNet++ v2 version of Concerto's pilot study (NeurIPS 2025, Sec. 2.1, Table 1). Frozen encoders,
one linear probe per feature set, top-100 semantic classes, scored on all 50 val scenes with the
official toolbox. Concerto's ScanNet linear-probe numbers: DINOv2 63.1, Sonata 72.5, concatenation 75.9 mIoU.

| Config | Features |
|---|---|
| A | DINOv2 ViT-L/14 (518 px), lifted to points |
| B | Utonia |
| C | Utonia ⊕ DINO (also with both blocks PCA-reduced to equal width) |
| S | Sonata (sanity check: Concerto reports 38.9 mIoU linear probing on ScanNet++ val) |
| S+ | Sonata ⊕ DINO |
| R | untrained PTv3 with Utonia's architecture, alone and ⊕ DINO |
| X | raw xyz, colour, normal |

## Steps

| Step | What | State |
|---|---|---|
| 1 | Encoder setup: loading, inputs, scale, upcast features, T4 time and memory | code ready; run `notebooks/pilot_01_encoders.ipynb` |
| 2 | Lift DINO features to points (≈30 DSLR views, occlusion test, visual check) | not started |
| 3 | Training features: ≤10k labelled points × 200 train scenes, fp16 | not started |
| 4 | Linear probes, 3 seeds per configuration | not started |
| 5 | Evaluation on 50 val scenes; write-up in `docs/pilot_concat.md` | not started |

What was verified, and the choices made: `docs/decisions.md` (2026-10-24, P1).

## Files

- `encoders.py`: load Utonia / Sonata / untrained PTv3 for a T4 (pinned HF weights, no FlashAttention,
  SDPA attention), per-encoder input transform, `encode()` → upcast features + input→voxel index.
- `scenes.py`: numpy scene helpers (Pointcept-format scene dirs; tiling for the size benchmark).
- `step1_encoders.py`: step 1 entry point (checks on Pointcept's public demo room, then time/memory per scene).
- `notebooks/`: Kaggle notebooks, generated by `scripts/make_notebooks.py`.

Imports: `PYTHONPATH=src:third_party/utonia:third_party/sonata` (the notebooks set it).
